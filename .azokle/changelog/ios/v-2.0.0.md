# Azokle iOS Release v2.0.0 (Build 10) Changelog

## 📱 Sovereign iOS Architecture & 100% Feature Parity with Android

### 1. Design System & Theme Alignment (`AzokleTheme.swift`)
- **Pixel-Perfect Color Palette**: Direct port of `Color.kt` to SwiftUI, incorporating:
  - Deep luxury dark canvas (`#101010`), elevated surface cards (`#181818`), and interactive surfaces (`#222222`).
  - Warm eye-friendly ivory light mode (`#FAF8F5`).
  - Strict semantic status tokens: Success Green (`#22C55E`), Tor Purple (`#A855F7`), Fire Orange (`#FF4500`), and Cyan Accent (`#38BDF8`).
- **Standardized Border Radius**: Applied `AzokleRadius` tokens (small: 8pt, medium: 14pt, large: 20pt, pill: 999pt).

### 2. Native WebKit Engine with Azokle Sovereign Shield (`WebViewContainer.swift`)
- **WKWebView Bridge**: High-performance `UIViewRepresentable` binding `WKWebView` with `BrowserState`.
- **Pre-Execution Scriptlet Injection**: Injects the Azokle Shield scriptlet at `document_start` via `WKUserScript`:
  - Enforces `hardwareConcurrency` (4 cores) and `deviceMemory` (8 GB) uniformity.
  - Implements Battery API dummy response (`level: 1.0`, `charging: true`).
  - Sanitizes outgoing WebRTC SDP manifests to neutralize local LAN IP exposure (`typ host` / RFC 8828).
- **Smooth Frame Progress Tracking**: KVO observation of `estimatedProgress`, `title`, `url`, `canGoBack`, and `canGoForward`.

### 3. Top Omnibar & Bottom Navigation (`BrowserOmnibar.swift` & `BrowserBottomBar.swift`)
- **Top Omnibar**:
  - Live Shield badge with blocked trackers count badge.
  - Host capsule with anti-spoofing host extraction and SSL lock status.
  - Reader mode toggle and responsive linear progress bar.
  - Reload / Stop navigation action.
- **Bottom Navigation Bar (5 Items)**:
  1. **Home**: Fast navigation to `https://search.azokle.com`.
  2. **Discover**: Opens Discover & Privacy Radar screen.
  3. **Active Tabs Counter**: Displays open tab count in rounded rectangular badge; opens Tab Switcher.
  4. **Fire / Burn**: Instant trigger for Incineration sheet.
  5. **3-Dots Menu**: Opens the comprehensive browser sheet.

### 4. Omnibox & URL Search Modal (`OmniboxSheet.swift`)
- **Search Engine Dropdown**: Supports Azokle Sovereign, DuckDuckGo, Brave, Startpage, Google, and Bing.
- **Auto-Focused Search Input**: Quick-clear button, keyboard submission handling.
- **Quick Access Shortcuts**: Curated direct links for sovereign browsing.

### 5. Multi-Mode Tab Switcher (`TabsScreen.swift`)
- **3 Tab Modes**: Standard Tabs, Private Tabs (Incognito), and Tor Circuit Tabs.
- **2-Column Responsive Card Grid**: Thumbnail previews, favicon, title, URL, close button (X), and active tab outline.
- **Tab Lifecycle**: New Tab creation, individual tab close, and bulk "Close All Tabs" by mode.

### 6. Privacy Shield Modal (`PrivacyShieldSheet.swift`)
- **Real-Time Defense Dashboard**: Displays live counts for trackers and ads blocked.
- **Protection Pillars**: Trackers & Analytics, Ad Network Suppression, Canvas & Fingerprint Shield, HTTPS Everywhere.
- **Global & Per-Site Toggle**: Instant control over content blocking rules.

### 7. Fire Incineration & Data Burn (`BurnConfirmationSheet.swift`)
- **One-Tap Purge**: Destroys active tabs, cookies, local storage, and WebKit cache via `WKWebsiteDataStore.default().removeData(...)`.
- **Haptic & Visual Flame Feedback**: Animated incinerate confirmation with full UI state reset.

### 8. Tor Onion Circuit Visualizer (`TorCircuitSheet.swift`)
- **3-Hop Stepper Topology**: Visual representation of client device -> Guard node -> Middle relay -> Exit relay -> Destination.
- **Live Circuit Rotation**: "Request New Tor Circuit" button for dynamic circuit rebuilding.

### 9. Management Screens
- **`HistoryScreen.swift`**: Chronological visited pages list with search and 1-tap clear.
- **`BookmarksScreen.swift`**: Saved bookmarks list with "Add Current Tab".
- **`DownloadsScreen.swift`**: File downloads monitor.
- **`SettingsScreen.swift`**: Search engine selector, shield toggles, Tor configuration, cache cleaner, and version details.
- **`DiscoverScreen.swift`**: Trending privacy radar topics and direct links.
