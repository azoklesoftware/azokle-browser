### 14. Comprehensive Security Audit, Vulnerability Mitigations & UI Defenses
- **WKWebsiteDataStore Isolation for Private & Tor Modes**:
  - *Vulnerability Fixed*: Previously, `WKWebView` used persistent disk storage (`WKWebsiteDataStore.default()`) indiscriminately, leaking session cookies, localStorage, and cached network traces from Private and Tor Circuit tabs to the device disk.
  - *Mitigation*: Dynamically assigns `configuration.websiteDataStore = WKWebsiteDataStore.nonPersistent()` whenever `tab.isPrivate || tab.isTor`. Guarantees 100% ephemeral in-memory storage that evaporates immediately when tabs are closed.
- **Target `_blank` Tab Hijack & Isolation Containment**:
  - *Vulnerability Fixed*: `createWebViewWith` loaded new window requests (`target="_blank"`) directly into the current web view, overriding the active browsing session and potentially breaching Tor/Private isolation.
  - *Mitigation*: Intercepts `navigationAction.targetFrame == nil` requests and safely dispatches `state.openNewTab(url:..., isPrivate:..., isTor:...)`, ensuring popup and target `_blank` links inherit the parent tab's strict security partition.
- **Self-XSS & Scheme Safety Interception**:
  - *Vulnerability Fixed*: Raw inputs starting with `javascript:`, `data:`, or `file:` could execute untrusted script or trigger unexpected local URL access.
  - *Mitigation*: Sanitizes omnibar navigation in `BrowserState.navigateActiveTab(to:)` by treating dangerous scheme prefixes as search queries. In `WebViewContainer.swift`, `decidePolicyFor navigationAction` restricts navigation to `http`, `https`, and `about`, delegating system intents (`tel:`, `mailto:`, `sms:`) to `UIApplication.shared.open`.
- **Reactive Web Action Dispatcher**:
  - *Bug Fixed*: Web navigation commands (Back, Forward, Reload, Stop) had no execution bridge to the underlying `WKWebView`.
  - *Mitigation*: Introduced `WebAction` enum (`goBack`, `goForward`, `reload`, `stop`) and reactive `@Published var pendingAction: (UUID, WebAction)?` in `BrowserState`. Integrated responsive Back and Forward buttons with active state binding in `BrowserMenuSheet.swift` and Stop/Reload controls in `BrowserOmnibar.swift`.
- **Safe Index Mapping for History & Bookmarks Deletions**:
  - *Bug Fixed*: In `HistoryScreen.swift` and `BookmarksScreen.swift`, swiping to delete while filtering by search text removed incorrect entries or triggered `IndexSet` out-of-bounds crashes due to filtered-versus-source index offsets.
  - *Mitigation*: Mapped `IndexSet` indices back to their canonical UUIDs before deleting from the primary data collection.
- **SwiftUI Nested Button Tap Deconfliction in Tabs Screen**:
  - *Bug Fixed*: In `TabsScreen.swift`, wrapping the tab card in a SwiftUI `Button` with a nested close `Button` (X) caused touch hit-testing collisions and unpredictable tap interception.
  - *Mitigation*: Converted the outer card to a `VStack` with `.contentShape(Rectangle()).onTapGesture`, ensuring clean, independent tap boundaries for card selection and tab dismissal.
- **Anti-Spoofing Host Prefix Stripping**:
  - *Bug Fixed*: `cleanHost` in `BrowserOmnibar.swift` used `host.replacingOccurrences(of: "www.", with: "")`, which corrupted domains containing `www.` in non-prefix positions (e.g., `mywww.com` -> `my.com`).
  - *Mitigation*: Replaced with strict prefix check: `if host.hasPrefix("www.") { host.dropFirst(4) }`.
