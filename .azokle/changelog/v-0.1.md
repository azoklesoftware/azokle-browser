# Azokle Browser Monorepo Core v0.1.0 Changelog

## 🌐 Universal Multiplatform Architecture (Android, iOS, macOS, Windows, Linux)

### 1. Monorepo Modular Crate Ecosystem (`crates/*`)
- **`crates/protocol` (AUBP v1.0.0)**: Authoritative universal messaging and state synchronization envelope supporting Commands, Requests, Responses, Events, and Standard Errors across all target platforms.
- **`crates/tabs`**: Cross-platform tab management, session persistence, domain grouping, and LIFO undo stacks with strict zero-disk ephemeral sandboxing.
- **`crates/networking`**: Pure-Rust RFC 8484 DNS-over-HTTPS, RFC 1928 SOCKS5 proxy engine, and SSRF loopback/private IP filtering.
- **`crates/crypto`**: Argon2id key derivation, ChaCha20-Poly1305 AEAD vault encryption, and WebAuthn P-256 / Ed25519 passkey signing with zeroize on drop.
- **`crates/permissions`**: Dual-partitioned origin permission management with private session isolation.
- **`crates/history`**: High-performance browsing history recording, time-range purges, and disk JSON synchronization.
- **`crates/bookmarks`**: Hierarchical bookmark tree storage, searching, and JSON backup/restore.
- **`crates/tor`**: Native Tor controller and circuit rotation manager (`SIGNAL NEWNYM`).
- **`crates/adblock` & `crates/tracker-block`**: High-speed ABP-syntax rule matcher with Aho-Corasick domain filtering and URL parameter stripping.
- **`crates/storage`**: Thread-safe persistent settings and search engine preferences.
- **`crates/security`**: Cosmetic style rule generation and scriptlet defusers.
- **`crates/azokle-core`**: Centralized engine facade uniting all 16 crates with universal protocol dispatching.

### 2. Universal Wire Envelopes & FFI Bridges
- **`bindings/kotlin`**: Android JNI bridge with `std::panic::catch_unwind` safety and universal `protocolDispatch`.
- **`bindings/c`**: Universal C-ABI header and shared library bindings for Desktop and embedding targets.
- **Protocols & Schemas (`protocols/`)**: Universal JSON Schemas (`aubp-v1.json`, `tabs.json`, `permissions.json`, `tor.json`), IPC framing specifications, and UniFFI interface contracts.

### 3. Verification & Quality
- **39/39 Passing Tests**: Comprehensive unit, integration, serialization, and fuzz resilience tests.
- **ThinLTO Optimized**: Production release profiles with ThinLTO, single codegen units, and symbol stripping.
