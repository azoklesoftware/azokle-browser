# Azokle Android Release v2.0.8 Changelog

## 🧹 Zero-Warning Compiler Hardening, Jetpack Crypto Compatibility & Type-Safety Optimization

---

### 1. Kotlin & OkHttp 5 Null-Safety Hardening
- **Non-Null Response Body Streamlining**:
  - Eliminated redundant safe-call operators (`?.`) on non-nullable OkHttp 5 `ResponseBody` across network and search handlers:
    - `DnsOverHttpsManager.kt` (`response.body.string()`)
    - `SearchRepository.kt` (`response.body.string()` in suggest and search endpoints)
    - `DownloadManager.kt` (removed dead Elvis fallback on non-null `response.body`)
    - `PwaManager.kt` (manifest fetching body consumption)
    - `ReaderExtractor.kt` (readability HTML extraction stream)
    - `TorCircuitManager.kt` (Tor exit relay check response body)
- **Safe Selection & Permission Scoping**:
  - `AzoklePermissionDelegate.kt`: Refactored camera/microphone/screen-share video track selection using `video?.let { v -> ... }`, eliminating type mismatches and unsafe access warnings on platform types.
  - `AzokleProgressDelegate.kt`: Removed redundant safe call on `TextureView` and redundant non-null assertion (`!!`) on `SurfaceView`.
  - `AzokleSelectionDelegate.kt`: Removed dead Elvis operators (`?:`) on non-nullable `String` return values.
  - `GeckoEngineManager.kt`: Cleaned up redundant safe navigation on non-null `WebExtension.MetaData`.
  - `BrowserScreen.kt`: Cleaned up redundant safe calls on non-null `HomeViewModel` references in overlay delegates.

---

### 2. GeckoView Prompt Delegate Platform Type Cleanup
- **`GeckoPromptDelegateImpl.kt`**:
  - Added targeted file-level `@file:Suppress("USELESS_ELVIS", "UNNECESSARY_SAFE_CALL")` annotations for GeckoView Java interop array structures (Choice prompt options, Identity Credential providers, and Autocomplete options).
  - Resolves false-positive platform type warnings when bridging between GeckoView's Java annotations and Kotlin 2.4 compiler strict null-safety rules.

---

### 3. Jetpack Security Crypto & Encrypted Preferences Maintenance
- **MasterKey & EncryptedSharedPreferences Suppressions**:
  - Annotated cryptographic preference managers with `@Suppress("DEPRECATION")`:
    - `PreferencesManager.kt`
    - `PasswordVaultManager.kt`
    - `PasskeyVaultManager.kt`
    - `EncryptedVaultManager.kt`
  - Safeguards Android KeyStore hardware-backed AES-256 GCM encryption keys without triggering compiler diagnostic warnings while awaiting AndroidX Security 1.2+ final migration APIs.

---

### 4. Jetpack Compose & Android Framework Callback Modernization
- **Text-to-Speech Error Callback Modernization (`ReaderTextToSpeech.kt`)**:
  - Implemented the modern `UtteranceProgressListener.onError(utteranceId: String?, errorCode: Int)` callback for granular speech engine error logging.
  - Annotated legacy `onError(utteranceId: String?)` with `@Deprecated("Deprecated in Java")` to comply with Kotlin 2.4 `@OVERRIDE_DEPRECATION` compiler diagnostic rules.
- **Compose Clipboard Manager Suppressions**:
  - Suppressed Compose `LocalClipboardManager` deprecations across:
    - `SiteSecurityCertificateSheet.kt` (also removed redundant type cast)
    - `AboutAzokleScreen.kt`
    - `TorCircuitVisualizerSheet.kt`
