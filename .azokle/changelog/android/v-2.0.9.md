---

### 1. Modern Dependency Stack & Security Updates
- **Jetpack Compose BOM 2026 (`2026.09.00`)**:

### 2. Rust Core Workspace Hardening & Strict Lint Conformance
- **Clippy Clean Architecture Compliance**:
  - Eliminated all Clippy warnings under `-D warnings` across all workspace crates and FFI bindings:
    - **`crates/networking`**: Derived `Default` for `NetworkRoute`; factored complex DNS TTL cache types into `DnsCache` type aliases.
    - **`crates/privacy/adblock`**: Replaced string slice push allocations with char-literal `push('\n')`.
    - **`crates/services/history`**: Migrated manual sort closures to canonical `sort_by_key(|b| std::cmp::Reverse(...))`.
    - **`crates/services/search`**: Streamlined search engine bang parsing (`!yt`, `!w`, `!gh`) using direct `strip_prefix.map` closures.
    - **`crates/protocol`**: Removed unused domain payload test imports.
    - **`crates/core`**: Cleaned up shadowed re-exports from `azokle_common`.
    - **`bindings/c` & `bindings/uniffi`**: Implemented `Default` for `UniversalBrowserEngine` and applied safe FFI raw-pointer dereference annotations.
- **CI Resilience for Adblock Live Tests**:
  - Refactored `crates/privacy/adblock-rust/tests/live.rs` to gracefully skip live tests when unversioned upstream filter data (`data/live-filters.txt`) is absent, preventing spurious CI test suite panics on clean runner checkouts.

### 5. Tab Group Security, Privacy Isolation & Ghost Pruning Hardening
- **Rust Domain Clustering Isolation (`crates/services/tabs`)**:
  - Enforced mode-specific cluster prefixing (`group_std_`, `group_priv_`, `group_tor_`) in `auto_group_by_domain()`, preventing cross-mode tab correlation across Tor, Private, and Standard cleartext browsing sessions.
- **Parent-Child Group Inheritance Hardening (`TabManager.kt`)**:
  - Standalone fallback when opening tabs with null parents, preventing orphaned `targetGroupId` values.
  - Mode mismatch isolation ensuring child tabs never inherit private/Tor groups into standard browsing or vice versa.
- **Ghost Group Elimination & Atomic State Pruning**:
  - Fixed dual-source-of-truth desynchronization by atomically removing moved tabs from previous groups and pruning empty ghost groups in `createGroup()` and `addTabToGroup()`.
  - Disbanded 0-tab groups automatically on tab removal in `removeTabFromGroup()`.
  - Filtered empty groups on SQLite database session restoration in `AzokleHistoryDatabase.kt`.
- **Undo Support for Group Closures**:
  - `closeGroup()` now records non-private tabs into the thread-safe `_recentlyClosed` deque, enabling 1-tap undo for accidental tab group closures.
- **Modal Lifecycle Synchronization (`TabGroupDetailSheet.kt` & `BrowserScreen.kt`)**:
  - Integrated `LaunchedEffect(tabs.isEmpty())` auto-dismissal to prevent frozen dialogs when the last tab of a group is closed.

### 7. Android Autofill Framework, Password Manager Integration & External Intent Dispatching
- **Android Autofill Framework Bridge**:
  - Connected `GeckoView.setAutofillEnabled(boolean)` and `importantForAutofill` in `GeckoBrowserView.kt` to the Android OS Autofill Framework, enabling seamless autofill overlay and inline suggestions with external password managers (Bitwarden, 1Password, Google Autofill, KeePass).
  - Enforced strict privacy and anonymity boundaries: autofill virtual structure exposure is automatically disabled in Private Browsing and Tor mode to prevent credential cross-contamination and fingerprinting leaks.
- **GeckoView Autocomplete Engine Integration (`AzokleAutocompleteStorageDelegate`)**:
  - Implemented `Autocomplete.StorageDelegate` bridging Mozilla GeckoView Quantum's internal autofill engine to the hardware-backed `PasswordVaultManager`.
  - Enabled native login autofill (`loginAutofillEnabled(true)`) in `GeckoRuntimeSettings`.
- **Intelligent Save vs. Update Password Prompts (`GeckoPromptDelegateImpl`)**:
  - Added smart credential existence detection (`isUpdateLoginPrompt`), dynamically toggling prompt dialog titles, messages, and action buttons between "Save Password" and "Update Password" based on existing vault records for the origin.
- **External App Link & Share Sheet Handling (`ACTION_SEND`)**:
  - Added `<intent-filter>` for `android.intent.action.SEND` with MIME type `text/plain` to `MainActivity` in `AndroidManifest.xml`.
  - Implemented URL extraction and tracking-parameter sanitization (`UrlHelper.extractUrl`) for shared plain-text URLs and messages received from other Android apps.

### 8. Production-Grade Privacy Shield, Cookie Controls & Fingerprinting Defense
- **Comprehensive Ad & Tracker Shield Pipeline**:
  - Implemented multi-tier protection supporting Aggressive, Standard, and Off blocking modes across GeckoView, Rust native engine, and the WebExtension shield.
  - Added triple cookie controls in Privacy Shield Sheet and Settings Screen: **Block Third-Party Cookies** (default with Total Cookie Protection origin isolation), **Block All Cookies**, and **Allow Cookies**.
  - Enabled Master Fingerprinting Protection by default, backed by fine-grained configurable controls: font visibility level 1 (`layout.css.font-visibility.level`), screen resolution letterboxing (`privacy.resistFingerprinting.letterboxing`), and user-agent hardware concurrency spoofing.
  - Integrated GeckoView automated Cookie Banner Reduction & Auto-Reject (`cookiebanners.service.mode: 2`, `cookiebanners.bannerClicking.enabled: true`, and `cookiebanners.cookieInjection.enabled: true`) across standard and private browsing modes.

---

### 9. Multi-Tier Security, Vulnerability & Telemetry Audit Fixes
- **Telemetry Double-Counting Elimination**:
  - Removed query-time counter pre-increments from JNI `checkUrl`, `checkNetworkRequest`, and `checkUrlFast`, ensuring telemetry counters strictly record actual enacted blocks in `recordBlock`.
- **Rust AdBlock Engine Inferred Categorization**:
  - Implemented `infer_category(url, matched_rule)` in `crates/privacy/adblock`, dynamically classifying blocked requests into `Tracker`, `Telemetry`, `Fingerprinting`, `Cryptomining`, `Annoyance`, or `Ad`.
  - Added fallback check to `core.trackers.is_tracker(host)` in JNI request checks to resolve trackers not yet in filter rule sets.
- **Strict Tab-Scoped Ethical Ad Click Attribution**:
  - Patched cross-tab attribution leak in `extensions/azokle-shield/background.js`: updated `isAdClickExempt` to strictly enforce `details.tabId` matching.
  - Connected `AdClickManager.registerAdClick` in `BrowserScreen.navigateToUrl` and `AzokleNavigationDelegate.onLocationChange` prior to tracking parameter query stripping.
- **Dynamic Shield Blocking Modes & Active Session Synchronization**:
  - Synchronized `blockingMode` with WebExtension background script: immediately bypasses filtering when `off` and fast-paths CNAME subdomains and social beacons in `aggressive` mode.
  - Added `TabManager.updateTrackingProtectionOnActiveSessions` to dynamically toggle `settings.useTrackingProtection` across all active warm tabs without requiring page reloads.
