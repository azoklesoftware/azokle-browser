### 16. Web Navigation Crash Elimination & History Purge Persistence Guarantee
- **UnsatisfiedLinkError Website Navigation Crash Resolved**:
  - Recompiled multi-architecture release native binaries (`arm64-v8a`, `armeabi-v7a`, `x86_64`) containing the newly exported `Java_com_azokle_search_core_AzokleCore_historyUpdateTitle` symbol using `cargo ndk`.
  - Hardened JNI entry points in `AzokleCore.kt` and `HistoryManager.kt` by catching `Throwable` (rather than just `Exception`), ensuring that any runtime linkage discrepancy degrades gracefully without triggering an uncaught `Error` crash.
- **Root-Cause Resolution of History Persistence on Clear**:
  - **SQLite Transaction Rollback Fix**: Removed direct `DELETE FROM TABLE_PLACES_FTS` within `clearAllSecurely()`. Because `TABLE_PLACES_FTS` is an external-content virtual table (`content='azokle_places'`), direct deletion threw an SQLiteException that silently caused Android SQLite transactions to roll back all deletions in `TABLE_PLACES` and `TABLE_VISITS`. Added dedicated `clearAllHistory()` and updated `clearTimeRange()`.
  - **Coroutine Self-Cancellation Fix**: Replaced parent supervisor job cancellation in `clearAllSync()` with targeted debounced `saveJob?.cancel()` and guarded execution within `withContext(NonCancellable)` so history clearing is never aborted midway.
  - **Cold-Start Re-import Guard**: Updated `saveToDisk()` to unconditionally purge the on-disk JSON cache (`azokle_browser_history.json`) when history is empty, preventing `loadHistory()` from re-importing purged entries on next cold start.
  - **Settings Integration**: Unified "Clear Browsing & Search History" in `SettingsScreen.kt` to trigger both `prefsManager.clearRecentSearches()` and `HistoryManager.clearAll()`.

### 20. Security Audit Remediations — High-Severity Vulnerability Elimination (H-1 through H-8)
- **H-1: Tor Routing Bypass & DNS Leak Elimination (`extensions/azokle-shield/background.js`)**:
  - Replaced naive substring checking (`url.indexOf('.onion') !== -1`) with strict URL hostname parsing (`host === 'onion' || host.endsWith('.onion')`), eliminating false-positive query/path routing.
  - Implemented fail-closed security for all `.onion` requests and Tor private sessions: routes through dead local blackhole proxy (`127.0.0.1:1`) if Tor daemon is inactive or SOCKS port is invalid, strictly forbidding fallback to `{ type: 'direct' }` and preventing DNS leaks to ISP resolvers.
- **H-2: WebRTC IP Leak Prevention & Network Hardening (`GeckoConfigManager.kt`)**:
  - Enforced `media.peerconnection.ice.proxy_only: true` to prevent WebRTC ICE candidates from bypassing configured SOCKS5 proxies.
  - Disabled silent proxy failover with `network.proxy.failover_direct: false` to ensure requests fail closed on proxy dropouts.
  - Disabled speculative network connections and DNS prefetching (`network.dns.disablePrefetch: true`, `network.prefetch-next: false`, `network.http.speculative-parallel-limit: 0`).
- **H-3: Intent Scheme URI Smuggling & Anti-Self-Targeting (`IntentParser.kt`, `NavigationSecurity.kt`, `ExternalAppLauncher.kt`)**:
  - Stripped all untrusted extras via `intent.replaceExtras(null as Bundle?)` and `sanitized.replaceExtras(null as Bundle?)` to neutralize serialized object deserialization and internal state overwrite exploits.
  - Enforced `Intent.CATEGORY_BROWSABLE` unconditionally across all parsed custom and intent-scheme URIs.
  - Blocked self-targeting exploits (`pkg.equals("com.azokle.search")` or `pkg.equals("com.azokle.browser")`), returning `SECURITY_REJECTED` to prevent internal component traversal.
  - Restamped `ALLOWED_ACTIONS` whitelist to only `ACTION_VIEW` and `ACTION_DIAL`.
- **H-4: Credential Autofill Origin Matching & PSL Domain Isolation (`PasswordVaultManager.kt`, `AzokleAutocompleteStorageDelegate.kt`)**:
  - Replaced naive suffix matching with a robust Public Suffix List resolver supporting multi-part TLDs and shared-hosting domains (`.co.uk`, `.github.io`, `.pages.dev`, `.herokuapp.com`, etc.).
  - Enforced strict origin matching: HTTPS scheme requirement, exact port matching, and exact host / parent-child subdomain match while preventing sibling subdomain cross-talk (`accounts.example.com` vs `uploads.example.com`).
  - Closed fail-open behavior in `AzokleAutocompleteStorageDelegate.kt`: blank or invalid domains strictly return empty credentials.
- **H-5: DOM XSS in Tab Strip Favicon Rendering (`TabStrip.ts`, `index.html`)**:
  - Eliminated `innerHTML` interpolation of `tab.favicon`; dynamically constructed DOM `<img>` elements via `document.createElement('img')` and `replaceChildren()`.
  - Enforced protocol whitelisting (`https:`, `http:`, `data:image/`) and URL parsing, rendering fallback plain-text indicators on non-whitelisted protocols.
  - Implemented Content Security Policy `<meta>` tag in `index.html` blocking untrusted scripts and object embeds.
- **H-6: Rust HTTP Client Plaintext Socket TLS Enforcement (`crates/networking/src/client.rs`)**:
  - Explicitly failed closed on HTTPS URLs with `NetworkError::TlsError`, preventing unencrypted plaintext transmission over port 443.
  - Added strict CRLF header validation (`\r` and `\n` detection) to prevent HTTP request smuggling and response splitting.
  - Capped response body reading to 10 MB (`take(MAX_RESPONSE_BYTES)`) to prevent OOM denial of service from unbounded streams.
  - Fully parsed response headers into `HttpResponse.headers` and updated `.onion` routing to parse hostname.
- **H-7: Vault Plaintext Fallback Elimination & Atomic Fail-Closed Keystore (`PasswordVaultManager.kt`, `EncryptedVaultManager.kt`, `PasskeyVaultManager.kt`, `PreferencesManager.kt`)**:
  - Completely removed unencrypted fallback SharedPreferences files (`${PREFS_FILE}_fallback`, `FALLBACK_PREFS_FILE`).
  - Removed silent `keyStore.deleteEntry()` and `deleteSharedPreferences()` on initialization failure, protecting user credentials from permanent deletion on transient Keystore locks.
  - Added exponential backoff retry (3 attempts) on Keystore initialization and failed closed with `SecurityException` if hardware Keystore is permanently unavailable.
- **H-8: Release Pipeline Signing Gate & Artifact Verification (`release.yml`, `fdroid.yml`)**:
  - Enforced strict presence and non-emptiness validation for `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, and `ANDROID_KEY_ALIAS`, terminating CI with `exit 1` if signing credentials are missing.
  - Removed `assembleDebug` fallback from release and F-Droid workflows, ensuring only release build flavors (`assembleRelease`) are built.
  - Added `apksigner verify --verbose` validation on all generated release APKs.
  - Restricted release asset publication pattern strictly to `apps/android/app/build/outputs/apk/release/*.apk`.
