## ⚡ Crash Investigation & Dual Root-Cause Resolution

### 51. Physical Device Crash Resolution & Native Library Compilation (`libazokle_core.so` & `AzokleCore.kt`)

- **Dedicated Theme-Adaptive Transition Layer (`PageLoadingTransitionSurface.kt`)**: Implemented an opaque, theme-synchronized Compose loading surface (`PageLoadingTransitionSurface`) placed above `GeckoBrowserView`. The surface presents a modern, shimmering web page skeleton layout and a destination domain status pill with pulsing indicator, completely shielding the viewport from any stale frame flashes.
- **Smooth Transition Timing**:
  - Activated immediately (`isPageTransitioning = true`) upon user navigation from Home, Discover, Bookmarks, History, or Omnibar.
  - Automatically dismissed via smooth alpha fade-out (`tween(180)`) once Gecko signals initial DOM layout paint (`progress >= 25`) or complete page readiness (`!isLoading`), with a 4-second safety timeout.
- **Tab Loaded State & Session Cleanup**:
  - Updated `onHomeClick`, `BackHandler`, and `BrowserErrorScreen.onHome` to call `TabManager.clearTabLoaded(activeTabId)`, `isPageTransitioning = false`, `targetLoadingUrl = ""`, and `geckoSession?.stop()`.
  - Guaranteed that subsequent navigation to any URL (including repeated visits to the same site) reliably triggers a fresh load and clean transition without displaying previous website content.
- **Native Surface Background Synchronization (`GeckoBrowserView.kt`)**: Set native background color on `GeckoView` and `SwipeRefreshLayout` matching `isDarkMode` (`#121212` for dark, `#FFFFFF` for light), eliminating white or unstyled surface flashes during view re-attachment.
- **Full State Preservation**: Preserved browser history, back navigation, cookies, JavaScript, and multi-tab session architecture with zero session destruction.
