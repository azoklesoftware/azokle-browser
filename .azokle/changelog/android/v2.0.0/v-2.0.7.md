# Azokle Android Release v2.0.7 Changelog

## ⚡ History Engine Virtualization Overhaul, Modern Toolchain Upgrade & Core Dependency Hardening

---

### 1. History Screen Performance & Virtualization Overhaul
- **Zero-Latency Virtualized History List (`HistoryScreen.kt`)**:
  - Replaced the eager nested `Column` layout (`item { Column { items.forEachIndexed } }`) with true flat virtualization using `LazyColumn` (`item(key = "header_...")` and `itemsIndexed(key = { it.id })`).
  - Eliminates multi-second rendering delays and UI stalls when opening the History screen with hundreds of entries.
- **Asynchronous Date Grouping off Main Thread**:
  - Replaced synchronous UI-thread calendar calculations with `produceState` dispatched on `Dispatchers.Default`.
  - Date boundaries ("Today", "Yesterday", "Last 7 Days", "Last 30 Days", "Older") are computed asynchronously in the background, keeping frame delivery at a solid 60/120 FPS.
- **Progressive Windowed Pagination**:
  - Implemented progressive windowing loading an initial 50 items on open, automatically expanding as the user scrolls.
  - Guarantees immediate 0ms first-frame render regardless of database size.
- **Dynamic Grouped Card Border Modifier (`Modifier.historyCardItem`)**:
  - Implemented a custom draw-time modifier for history items that dynamically handles top/bottom rounded corner shapes and continuous hairline borders.
  - Eliminated nested Card composable wrappers and double-border overlap artifacts while maintaining premium visual aesthetics.
- **Non-Blocking Lazy Parsing (`HistoryItem.kt`)**:
  - Optimized `cleanHost`, `displayTitle`, `faviconUrl`, and `formattedTime` using `by lazy(LazyThreadSafetyMode.NONE)`.
  - Heavy URI parsing and time formatting now execute only when an individual item enters the active viewport.
- **Coil Favicon Request Caching (`FaviconImage.kt`)**:
  - Wrapped `ImageRequest` instances in `remember` keys to avoid re-allocating network/cache loader objects on list recompositions.
- **Debounced Storage Persistence (`HistoryManager.kt`)**:
  - Added a 2,000ms debounce job to history disk writes, preventing I/O thrashing during rapid page navigation.
- **Fluid Overlay Visibility (`BrowserModalOverlaysHost.kt`)**:
  - Wrapped `HistoryScreen` in `AnimatedVisibility` with smooth 160ms fade-in and 140ms fade-out transitions.
