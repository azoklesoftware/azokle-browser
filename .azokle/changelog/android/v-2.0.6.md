# Azokle Android Release v2.0.6 Changelog

## 🛡️ Edge Gesture Navigation Hardening, Data Incineration Isolation & Deep/App Link Engine Overhaul

---

### 1. Link Context Menu & Edge Back Gesture Hardening
- **System Edge Gesture Exclusion Zone (`NestedGeckoView.kt`)**:
  - Implemented 32dp edge gesture exclusion zones along the left and right screen borders.
  - Suppressed `parent?.requestDisallowInterceptTouchEvent(true)` when touches originate in the edge back-gesture region, giving Android OS gesture navigation and predictive back full authority.
  - Prevents GeckoView's APZ (Asynchronous Pan/Zoom) engine from falsely detecting long presses on hyperlinks or media elements when a user pauses or holds their finger down during back gestures ("hold back").
- **Edge Coordinate Filtering & Active Tab Guard (`AzokleContentDelegate.kt`)**:
  - In `onContextMenu()`, validated `screenX` against system edge gesture boundaries (`screenX <= 32dp` or `screenX >= displayWidth - 32dp`), discarding long-press events generated during edge back gestures.
  - Added strict tab identity verification: only the currently active tab (`tabId == TabManager.activeTabId.value`) can emit context menu events.
  - Re-validated session state (`session.isOpen`) and active tab identity inside `mainHandler.post { ... }` prior to invoking `onLinkLongPressed(target)`, preventing queued looper messages from firing after back navigation.
- **Navigation Lifecycle Context Menu Invalidation (`BrowserScreen.kt`)**:
  - Automatically resets `activeLinkContextTarget = null` and dismisses floating text selections inside `LaunchedEffect(currentUrl, isPageTransitioning)` whenever a page transition begins or URL changes.
  - Explicitly resets `activeLinkContextTarget = null` in `BackHandler` before calling `geckoSession?.goBack()` or returning to the home screen.

---

### 2. Data Incineration Race Condition Elimination & State Shredding
- **Multi-File Tab State Shredding (`DataBurnEngine.kt`)**:
  - Hardened DoD-grade file shredder to destroy both current (`azokle_tabs_state_v1.json`) and legacy (`tabs_state.json`) tab backup files on disk during incineration.
- **Session Cache Zeroization (`TabManager.kt`)**:
  - Clears `sessionStateMap`, `loadedUrls`, and tab thumbnails upon session reset to eliminate zombie session states following deep burns.
- **Gecko Engine Delegate Guard Barriers (`AzokleContentDelegate.kt`, `AzokleNavigationDelegate.kt`)**:
  - Added fast-return guard barriers to `onTitleChange()` and `onLocationChange()` when `DataBurnEngine.isBurning()` or `HistoryManager.isIncinerating()` is active.
  - Prevents residual GeckoView callbacks from asynchronously writing titles, history entries, or URLs back into storage while data is being wiped.
- **Full UI & Session Reset in Master Controller (`BrowserScreen.kt`)**:
  - Completely resets browser UI state (active URL, title, loading progress, overlays, sheets, and GeckoView/GeckoSession references) upon triggering data burns.
  - Prevents detached coroutines or UI race conditions when incinerating data.

### 3. Settings Incineration Flow & Modal Orchestration
- **Top-Level Burn Orchestration (`SettingsScreen.kt`, `SettingsSheet.kt`, `BrowserModalOverlaysHost.kt`)**:
  - Plumbed `onBurnData` callback from `BrowserModalOverlaysHost` through `SettingsSheet` to `SettingsScreen`.
  - Triggering "Incinerate Browsing Data" from within Settings properly dismisses the sheet and delegates to the top-level `BrowserScreen` deep burn orchestration with full confirmation.

### 4. Deep Link & App Link Dispatching Architecture Overhaul
- **Custom Scheme `CATEGORY_BROWSABLE` Elimination (`ExternalNavigationHandler.kt`, `IntentParser.kt`, `OAuthRedirectHandler.kt`)**:
  - Removed forced `addCategory(Intent.CATEGORY_BROWSABLE)` on custom scheme intents (`whatsapp://`, `tg://`, `spotify://`, `zoommtg://`, `upi://`, `intent://`, and OAuth callbacks).
  - Matches the Android standard where third-party apps register custom schemes strictly with `CATEGORY_DEFAULT`. Eliminates `ActivityNotFoundException` when launching installed native applications from web links.
- **Direct Native App Package Targeting (`AppLinkHandler.kt`, `AzokleNavigationDelegate.kt`)**:
  - Updated `AppLinkHandler.openInNativeApp()` to explicitly set `intent.package` to the verified native app package (e.g. `com.google.android.youtube`, Maps, Reddit, Instagram).
  - Routed HTTP/HTTPS App Link navigation in `AzokleNavigationDelegate` through `AppLinkHandler`, completely breaking the circular loop where untargeted intents were routed back into Azokle Browser while GeckoView blocked the page.
- **Full Package Visibility for Web Schemes (`AndroidManifest.xml`)**:
  - Added `<data android:scheme="http" />` under `<queries>` alongside `https`, ensuring Android 11+ (API 30+) package visibility queries succeed for all web-based App Links.
- **Seamless Incoming Deep Link Display (`BrowserScreen.kt`)**:
  - Automatically dismisses tab grid sheets, menus, discover sheets, and settings overlays inside `LaunchedEffect(activeTabId)` when an external intent selects a new tab, presenting incoming deep links directly to the user.

### 6. GeckoSession PromptDelegate Engine Overhaul & Enterprise Security
- **100% GeckoView 154 PromptDelegate Coverage (`GeckoPromptDelegateImpl.kt`)**:
  - Implemented all 25 GeckoView PromptDelegate API callbacks, ensuring complete web platform standard compliance.
- **Popup Routing Engine & Gesture Verification (`onPopupPrompt`)**:
  - Fixed dead popup delegation where approved popups failed to open in new tabs; now properly executes `onPopupRequested` on the main thread after gesture verification and dangerous scheme validation.
- **Universal Multi-Host File & Folder Picking (`FilePromptHost.kt`, `MainActivity.kt`, `PwaActivity.kt`)**:
  - Introduced `FilePromptHost` contract implemented by both `MainActivity` and `PwaActivity`, resolving silent file upload failures in standalone PWAs.
  - Added support for folder tree uploads (`FilePrompt.Type.FOLDER`) via `Intent.ACTION_OPEN_DOCUMENT_TREE`.
- **Directory Upload Confirmation (`onFolderUploadPrompt`)**:
  - Implemented confirmation dialogs protecting users before uploading whole directories (`<input type="file" webkitdirectory>`).
- **Client TLS Certificate Authentication (`onRequestCertificate`)**:
  - Added enterprise and developer client TLS certificate selection (mTLS) backed by Android's native `KeyChain.choosePrivateKeyAlias(...)`.
- **Navigation & Redirect Guard (`onRedirectPrompt`)**:
  - Blocks dangerous pseudo-schemes (`javascript:`, `chrome:`, `resource:`, `file:`, `data:`, `jar:`) on automatic redirect prompts.
- **Tor & Private Browsing Isolation**:
  - Automatically suppresses and dismisses login credential saving (`onLoginSave`), login selection (`onLoginSelect`), payment card saving/autofill (`onCreditCard*`), address saving/autofill (`onAddress*`), FedCM federated identity sharing (`IdentityCredential`), and cross-origin WebAuthn passkey requests (`onWebAuthnRelatedOriginPrompt`) in Tor and Private tabs.
- **Lifecycle Dialog Registry & Memory Leak Elimination**:
  - Added synchronized weak dialog tracking (`dismissAllPendingDialogs()`), automatically dismissing open prompts during tab switches, session releases, and data incineration.
- **Material 3 / DayNight Styling**:
  - Replaced legacy `android.app.AlertDialog` with `MaterialAlertDialogBuilder` matching Azokle's modern dark theme tokens.
- **Automated Regression Verification (`GeckoPromptDelegateTest.kt`)**:
  - Added unit test suite covering popup restrictions, redirect security, Tor/Private sandboxing, and dialog lifecycle cleanup.
