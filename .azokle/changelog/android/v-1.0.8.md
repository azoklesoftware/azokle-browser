# Azokle Android Release v1.0.8 (Build 9) Changelog

## 🚀 Master Rust Core Migration & Universal Protocol Engine

### 1. Universal Browser Protocol Layer (`crates/protocol` & `AUBP v1.0.0`)
- **Single Source of Truth**: Established the Azokle Universal Browser Protocol (AUBP v1.0.0) defining stable, strongly typed messaging contracts (Commands, Requests, Responses, Events, and Standard Errors `1000..5999`).
- **Universal JNI Dispatcher**: Implemented `AzokleCore.dispatchProtocol(envelopeJson)` and native `protocolDispatch` JNI entry point, allowing Android UI to invoke tab lifecycles, DNS resolution, Tor circuit rotation, and search queries through a unified protocol contract.
- **Dual Wire Serialization**: Full support for zero-copy canonical JSON strings for JNI interop and compact binary CBOR byte streams for high-speed IPC.

### 2. Tab Lifecycle & Session Orchestration Subsystem (`crates/tabs`)
- **Native Rust Tab Manager**: Migrated tab creation, closure, active tab switching, domain auto-grouping, and LIFO recently-closed undo stacks into native Rust (`crates/tabs`).
- **Strict Ephemeral Privacy**: Private and Tor tabs are completely excluded from disk persistence (`tabExportPersistentJson` writes zero bytes to flash).
- **Monotonic Monotonic Counters**: Guaranteed collision-free tab ID generation using atomic 64-bit sequence counters.
- **`TabManager.kt` Synchronization**: Updated Android tab orchestration to delegate persistence and state syncing directly to `AzokleCore`.

### 3. Pure-Rust Async Networking & SOCKS5 Tunneling (`crates/networking`)
- **Eliminated Host Subprocess Execution**: Replaced external OS `curl` child process execution with a native pure-Rust TCP socket transport.
- **Native RFC 1928 SOCKS5 Protocol**: Built a pure-Rust SOCKS5 handshake engine with domain addressing (`ATYP = 0x03`) for isolated Tor routing (`127.0.0.1:9050`) and custom proxies.
- **Hardened SSRF Firewall**: Added strict normalization and blocking for IPv4-mapped IPv6 addresses (`::ffff:127.0.0.1`, `::ffff:10.0.0.1`) and cloud metadata endpoints (`169.254.169.254`).

## 🛡️ Security, Panic Safety & Memory Zeroization Hardening

### 1. FFI Panic Unwinding Immunity
- **`std::panic::catch_unwind` Protection**: Wrapped all native JNI and C-ABI export functions in `std::panic::catch_unwind(AssertUnwindSafe(|| { ... }))`.
- **Process Crash Elimination**: Guaranteed that internal Rust panics cannot unwind across FFI boundaries, eliminating Undefined Behavior and unrecoverable process crashes.

### 2. Ephemeral Memory Scrubbing & Zeroization
- **Passkey Secret Zeroization (`crates/crypto`)**: Implemented the `Drop` trait on `SovereignPasskey` to securely wipe raw private key bytes via `zeroize::Zeroize` the instant passkeys are dropped from RAM.
- **Private Tab Sanitization (`crates/tabs`)**: Added `TabSession::scrub_ephemeral()` which actively zeroizes URLs, titles, and group names in memory upon tab closure.

### 3. Android Keystore Recovery Resiliency (`PreferencesManager.kt`)
- **Automated Keystore Key Reset**: Replaced silent fallback to unencrypted SharedPreferences with an automated secure key reset and re-encryption pipeline when Android Hardware Keystore encounters corruption or OS upgrade resets.
