# Azokle Android Release v2.0.1 Changelog

## 🛡️ Stability, Security Hardening & Tab Orchestration Architecture

---

### 1. 🚀 Target `_blank` & Tab Grouping Crash Elimination (`TabGroupBottomStrip.kt` & `BrowserScreen.kt`)
- **Resolved Compose Runtime Internal Error**: Eliminated fatal `ComposeRuntimeError: Unexpected or incorrect use of the Compose internal runtime API (pending composition has not been applied)` that occurred when clicking on links with `target="_blank"` or invoking `window.open()`.
- **Eliminated 2D Focus Search Subcomposition Race**:
  - Identified that touching web links in GeckoView dispatched Android View focus events that prompted Compose `TwoDimensionalFocusSearch` to scan beyond layout bounds via `LazyLayoutBeyondBoundsProviderModifierNode.layout` -> `remeasureSync`.
  - Replaced `LazyRow` with an eager, high-performance scrollable `Row(modifier = Modifier.horizontalScroll(rememberScrollState()))` inside `TabGroupBottomStrip.kt`, removing `SubcomposeLayout` and `BeyondBoundsLayout` crash vectors entirely.
- **Stable Layout Keys**: Added explicit keys to interactive action cards (`key = "group_add_tab_card"` in `TabGroupDetailSheet.kt` and `key = "tab_group_add_tab_button"` in tab switcher strips) to prevent slot table key desynchronization during dynamic list mutations.
- **Eliminated Stale Session Mutation**: Fixed `BrowserScreen.onNewWindowRequested` to prevent executing `geckoSession?.loadUri()` against stale parent tab sessions during new tab selection.
- **Smooth Group Carousel Transitions**: Safeguarded `LaunchedEffect(activeTabId)` auto-scroll animations with strict bounds verification and `runCatching` resilience.

---

### 2. 🔒 Comprehensive Navigation Security & Scheme Firewall
- **Privileged Protocol Firewall**: Hardened `AzokleNavigationDelegate` and `IntentResolver` to strictly deny navigation requests to privileged or internal URI schemes (`file:`, `content:`, `chrome:`, `resource:`, `jar:`).
- **Tor & Private Tab Isolation**: Guaranteed that external Android AppLinks (e.g. YouTube, Reddit, Play Store) are strictly prevented from launching native apps when operating within Private or Tor browsing modes, eliminating hardware identity leakage.
- **Automated Security Regression Suite**: Added `SecurityRegressionUnitTest.kt` ensuring all security policies and forbidden protocol filters are validated on every build.

---

### 3. ⚡ GeckoView Engine Lifecycle & Tab Session Stability
- **Thread-Safe Tab Grouping**: Synchronized `TabManager.openTabFromParent()` state flow updates with the UI Main Looper to ensure seamless Compose snapshot reactivity when new tabs are spawned from existing tabs.
- **Optimized Surface Rendering**: Streamlined `BrowserEngineSurface` keying and native session binding to avoid redundant View allocations and prevent UI flickering during new tab creation.

---

### 4. 📦 Build & Release Artifacts
- **Automated Verification**: All Android unit tests (`./gradlew testDebugUnitTest`) passed successfully with zero failures.
- **Production Compilation**: Clean Gradle configuration cache reuse and signed APK compilation.
