# Azokle Linux Desktop Release v0.1.0 Changelog

## 🐧 Sovereign Linux Desktop Browser Core

### 1. Native C-ABI & Protocol Dispatch Integration (`bindings/c`)
- **Universal Protocol Dispatcher**: Integrated `azokle_protocol_dispatch` enabling native Linux UI shells (GTK / Qt / Slint / C++) to communicate with the Rust Core via AUBP v1.0.0 JSON envelopes.
- **FFI Panic Safety**: Wrapped all exported functions in `std::panic::catch_unwind` to protect host Linux desktop processes from unhandled unwinding panics.
- **Safe Memory Allocation & Cleanup**: Exported `azokle_string_free` and `azokle_decision_free` for leak-free C memory management.

### 2. Pure-Rust SOCKS5 & Tor Tunneling
- **Pure-Rust Networking**: Eliminated external subprocess dependencies (`curl`), using native TCP sockets with timeout management.
- **Tor Circuit Management**: Native socket interface to Tor Control Port (`9051`) supporting authenticated circuit switching and `.onion` name routing.
- **DNS Leak Prevention & DoH**: Native RFC 8484 DNS-over-HTTPS resolver supporting Cloudflare, Quad9, Mullvad, and AdGuard with automatic `.onion` leak shielding.

### 3. Sovereign Vault & Content Filtering
- **ChaCha20-Poly1305 Vault**: Hardware-independent encrypted storage for bookmarks, history, and user credentials.
- **Passkey Authenticator**: Built-in WebAuthn P-256 authenticator with automatic private key memory zeroization on drop (`zeroize::Zeroize`).
- **ABP-Syntax Ad & Tracker Shield**: Fast multi-threaded rule matching with cosmetic CSS injection and defuser scriptlets.

### 4. Build & Verification
- **Native x86_64 / aarch64 Linux Compilation**: Tested and verified across all 16 Rust workspace crates with ThinLTO release optimizations.
