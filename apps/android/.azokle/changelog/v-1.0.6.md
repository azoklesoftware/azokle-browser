# Azokle Android Release v1.0.6 (Build 7) Changelog

## 🎧 Seamless Background Audio Playback (Brave-Style Architecture)

### Continuous Background & Screen-Off Playback
- **Universal Background Media Execution**: HTML5 video and audio streams (YouTube, SoundCloud, Spotify Web, podcast players, news streams) continue playing uninterrupted when Azokle is minimized, when switching to another application, or when the device screen is locked.
- **Native GeckoView Quantum Media Engine**: Configured `GeckoSessionSettings.Builder().suspendMediaWhenInactive(false)` at the engine level, allowing uninterrupted audio decoding while maintaining 100% web standards compliance and zero prototype tampering.
- **DocShell Navigation Channel Protection**: Removed destructive `session.loadUri("javascript:...")` runtime calls, eliminating DocShell media pipeline resets during Activity state transitions.
- **Safe Ad Skipping**: Replaced legacy fast-forward intervals with non-destructive skip button triggers in `content.js`, ensuring video timelines are never mutated or forced to stop.
- **Audio Focus Transient Resilience**: Updated `AudioManager.OnAudioFocusChangeListener` in `MediaPlaybackManager.kt` to gracefully maintain playback during transient launcher window animations and Home swipe gestures.

## 🛡️ Session Isolation & Storage Security Hardening

### Comprehensive Cookie, Storage, and Tab Isolation Hardening
- **Tor Proxy Session Isolation**:
  - Hardened `background.js` proxy routing to enforce strict incognito session isolation (`requestInfo.incognito === true`), preventing standard browsing tabs and persistent cookies from leaking across Tor SOCKS5 exit nodes.
- **Top-Level IPC Origin Verification**:
  - Enforced `sender.frameId === 0` validation on all content script messages dispatched to native handlers, eliminating subframe message spoofing risks.
- **Ordered Memory & Disk Data Incineration**:
  - Re-ordered the "Burn Data" incinerator flow to terminate all active `GeckoSession` instances before executing `StorageController.clearData(ClearFlags.ALL)`, ensuring in-memory socket connection pools and memory cookie jars are completely destroyed.
- **Verified History Ingestion**:
  - Moved URL visit recording from `onLocationChange` to `onPageStop(success = true)` so failed, blocked, or insecure navigations are never committed to persistent history.
