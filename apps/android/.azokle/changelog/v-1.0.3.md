# Azokle Android Release v1.0.3 Changelog

## 🛡️ Core Engine, Stability & Architecture Fixes

### Multiprocess GeckoView Lifecycle Fix
- **Main-Process Guard**: Added `isMainProcess()` verification in `AzokleApplication.kt` to ensure database setup, lifecycle observers, and `GeckoRuntime` pre-warming only run in the primary application process.
- **Eliminated Crash Loops**: Prevented isolated GeckoView child processes (`:gpu_*`, `:tab_*`) from attempting duplicate initialization, resolving fatal `UnsatisfiedLinkError` exceptions on `nativeOnDeviceChanged`.
- **Safe Dynamic Theming**: Moved `preferredColorScheme` configuration in `GeckoEngineManager.kt` to execute safely after JNI initialization.

### Tor Onion Proxy & DNS Leak Prevention
- **RFC 1928 SOCKS5 Handshake Probing**: Replaced hardcoded 500ms bootstrap timeouts with active binary SOCKS5 socket handshakes (`probeSocks5Handshake`).
- **Adaptive Consensus Verification**: Implemented progressive backoff retries (1.5s, 3s, 5s, 7s, 9s) against `check.torproject.org` and `icanhazip.com`.
- **Zero DNS Leaks**: Created `TorRemoteDns` in OkHttp to eliminate local Android `Dns.SYSTEM` resolutions and force SOCKS5 `0x03 DOMAINNAME` remote resolution.
- **Fail-Closed WebExtension Routing**: Updated `azokle-shield/background.js` proxy listeners with immediate fallback to protect against early network race conditions.
