# Azokle Android Release v1.0.4 (Build 5) Changelog

## 🛡️ Tor Onion Routing & Zero-Leak Security Infrastructure

### WebExtension IPC & SOCKS5 Routing Overhaul
- **Native JNI IPC String Serialization**: Fixed a critical `Invalid event data for callback` JNI serialization error in `GeckoEngineManager.kt` by returning stringified JSON payloads from `WebExtension.MessageDelegate.onMessage`. This ensures `azokle-shield/background.js` reliably receives native app status on every poll without unhandled Promise rejections.
- **Private & Tor Tab Proxy Coverage**: Restored `"incognito": "spanning"` in `manifest.json` (v3.7) to guarantee that the `browser.proxy.onRequest` engine attaches to all private and Tor sessions (`usePrivateMode = true`), preventing direct cellular/Wi-Fi bypasses.
- **Fast-Path Status Synchronization**: Added synchronous status checks on `browser.webRequest.onBeforeRequest` and `webNavigation.onBeforeNavigate` to eliminate race conditions when launching Tor tabs.
- **WebRTC & ICE Leak Suppression (TOR-001)**: Enforced strict WebRTC privacy settings in Tor mode, preventing local interface STUN/TURN host candidate enumeration from leaking the real IP over UDP.
- **HTTP/3 QUIC Suppression (TOR-002)**: Prevented UDP QUIC connections from bypassing the TCP SOCKS5 proxy in Tor sessions.
- **GeckoView TRR DoH In-Tor Suppression (TOR-003)**: Ensured DNS lookups in Tor mode delegate 100% to SOCKS5 `proxyDNS: true` on the exit relay rather than external DoH resolvers.
- **Connection Pool Eviction (TOR-005)**: Added `SearchRepository.sharedClient.connectionPool.evictAll()` on Tor toggle to flush all idle TCP sockets between regular and Tor sessions.
- **Adaptive Circuit Consensus Backoff (TOR-006, TOR-007)**: Tuned exit IP check retry delays (`listOf(1200L, 2500L, 4500L, 7500L, 10000L)`) for faster initial connections and reliable fallback on congested mobile data.

## 🔒 Security Hardening & Vulnerability Remediation (AUDIT-0.4)

### Clipboard Privacy Protection (SEC-001)
- Patched `AzokleSelectionDelegate.kt` to deny programmatic clipboard read requests from arbitrary web pages (`AllowOrDeny.DENY`), preventing clipboard snooping.

### Drive-By Download Authorization (SEC-002)
- Added an interactive `DownloadConfirmationDialog` in `BrowserScreen.kt` and wired GeckoView download callbacks in `GeckoBrowserView.kt`. All file downloads now require explicit user confirmation before writing to storage.

### Isolated Shield Content Scripts (SEC-003)
- Hardened `manifest.json` and extension content scripts to isolate browsing context and prevent cross-session state leakage.

### Dynamic Quantum DNS over HTTPS (SEC-004)
- Updated `DnsOverHttpsManager.kt` to dynamically route DNS queries to the selected active provider (Cloudflare, Google, Quad9, AdGuard) with graceful system fallback.

### Sovereign AdBlock Whitelist Hardening (SEC-005)
- Refactored `isWhitelistedDomain` in `background.js` from loose substring matching to strict hostname equality and subdomain suffix checking (`.azokle.com`, `.cloudflare.com`).

### Tab Session Retention & Crash Resilience (SEC-006)
- Implemented `getOrCreateSession` in `TabManager.kt` and decoupled `GeckoBrowserView` Compose disposal from session termination, preventing tab reloads and state loss on navigation.

### Android FileProvider URI Safety (SEC-007)
- Eliminated `Uri.fromFile(file)` fallback in `DownloadManager.kt`, strictly using `FileProvider.getUriForFile` to prevent `FileUriExposedException` crashes on Android 7.0+.

### Permitted Blob & Data URI Schemes (SEC-008)
- Added explicit support for `blob:` and `data:` schemes in `GeckoBrowserView.kt` for seamless HTML5 downloads, canvas exports, and web app file generation.

### Session Cookie Forwarding in Downloads (SEC-009)
- Forwarded GeckoView request headers and session cookies into `DownloadManager.kt` OkHttp client to support authenticated and gated downloads.

### Authentic Modern Firefox User-Agent (SEC-010)
- Applied genuine Firefox `rv:154.0` User-Agent strings in `GeckoEngineManager.kt` and `GeckoBrowserView.kt` across both Mobile and Desktop modes to prevent Cloudflare Turnstile blocks and site breakage.

### HTML5 File Upload Prompt Delegate (SEC-011)
- Implemented `onFilePrompt` in `GeckoPromptDelegateImpl.kt` for native Android file picker integration on `<input type="file">` elements.

### Debounced History Persistence (SEC-012)
- Implemented a 2000ms debounce buffer in `HistoryManager.kt` to prevent disk I/O thrashing during rapid page redirects and heavy browsing.

### Build Configuration & Keystore Hardening (SEC-014)
- Removed debug keystore references from release signing configurations in `app/build.gradle.kts`.

### Search URL History Deduplication (SEC-015)
- Fixed `HomeViewModel.kt` to record computed destination URLs in browser history instead of raw search query parameters.

### Clean Codebase (SEC-013)
- Removed redundant dead-code components (`TabGridSheet.kt`) to streamline the UI architecture.
