# Azokle Android Release v1.0.7 (Build 8) Changelog

## 🎬 Uninterrupted Background Video & Audio Playback Architecture

### Main World Page Visibility API Shielding
- **Real Page Context (Main World) Script Injection**: Injected the continuous background playback engine directly into the webpage's **Main World** execution realm via inline `<script>` tags and `window.wrappedJSObject` at `document_start`.
- **Page Visibility API Neutralization**:
  - Overrode `document.hidden`, `document.webkitHidden`, `document.mozHidden`, and `document.msHidden` to always return `false` on both the active `document` and `Document.prototype`.
  - Overrode `document.visibilityState` to always return `'visible'`.
  - Overrode `document.hasFocus()` to always return `true`, preventing media players from triggering blur/focus loss pauses.
- **Listener Interception**:
  - Patched `EventTarget.prototype.addEventListener` to silently block webpage scripts (such as YouTube, Twitch, and Vimeo video players) from attaching `visibilitychange` event handlers.
  - Attached capturing event interceptors with `e.stopImmediatePropagation()` and `e.preventDefault()` for `visibilitychange`, `webkitvisibilitychange`, `mozvisibilitychange`, and `pagehide`.

---

## 🔒 Lock-Screen CPU & Network Stream Preservation

### System WakeLock & WifiLock Management
- **Hardware WakeLock Integration**: Integrated `PowerManager.WakeLock` (`PARTIAL_WAKE_LOCK`) in `MediaPlaybackService.kt` to keep CPU scheduling active when the device screen turns off or locks.
- **Continuous Network Streaming with WifiLock**: Added `WifiManager.WifiLock` (`WIFI_MODE_FULL_LOW_LATENCY` / `WIFI_MODE_FULL_HIGH_PERF`) to prevent Wi-Fi power-saving mode from throttling background socket buffers.
- **Lifecycle-Aware Power Management**:
  - Automatically acquires `WakeLock` and `WifiLock` when `PlaybackStatus == PLAYING`.
  - Safely releases locks on `PAUSE`, `STOP`, or service termination to conserve battery.
- **Manifest Permissions**: Declared `<uses-permission android:name="android.permission.WAKE_LOCK" />` in `AndroidManifest.xml`.

---

## 🔊 Audio Focus Conflict & Loopback Resolution

### Resilient Audio Focus Handling
- **System Sound Immunity**: Updated `AudioManager.OnAudioFocusChangeListener` in `MediaPlaybackManager.kt` so transient `AUDIOFOCUS_LOSS` events (triggered by device lock sounds, screenshot sounds, or app-switching animations) do not forcefully terminate media streams when background audio is enabled.
- **GeckoView Audio Pipeline Cooperation**: Eliminated internal audio focus contention between `MediaPlaybackManager` and GeckoView's native C++ media playback engine.

## 🛡️ Azokle Shield Core Extension Update v5.3

### YouTube Player Stream Protection & Ad Elimination
- **Guaranteed Media Stream Availability (`googlevideo.com`)**: Whitelisted `googlevideo.com` from network request interception to prevent false-positive blocks on real video media chunks.
- **YouTube Internal Player Protocol Protection**: Safeguarded YouTube's `/youtubei/v1/player`, `/api/stats/`, `/gen_204`, `/client_204`, and `/ptracking` endpoints, eliminating "This content isn't available. Try again later." errors.
- **DOM Player Integrity in `cosmetic.css`**: Preserved internal `.ytp-ad-module` and `.video-ads` containers to avoid breaking HTML5 video player initialization.
- **Safe Video Ad Acceleration**: Accelerated playback speed exclusively when `.ad-showing` is active, restoring normal playback speed immediately on main video content without corrupting Media Source Extensions (MSE) buffers.
- **Extension Update v5.3**: Bumped extension version to `5.3` in `manifest.json`.

## ⚡ Reload Page Loop & Media Switching Crash Elimination

### SPA / PushState Navigation Loop Prevention
- **`onLocationChange` State Synchronization in `GeckoBrowserView.kt`**: Synchronized `lastLoadedUrl = it` directly inside `GeckoSession.NavigationDelegate.onLocationChange` before dispatching `onUrlChanged`.
- **Eliminated Infinite Page Reloads**: Prevented `LaunchedEffect(url)` from interpreting in-page client-side router changes (`history.pushState`, video recommendation clicks, or redirect changes) as external URL requests.
- **Uninterrupted Video Playback**: Ensured clicking recommended videos on YouTube, Twitch, or Single Page Apps updates the Omnibar URL and tab title without resetting or reloading the active web session.

### Android 12+/14+ Foreground Service Crash Immunity
- **Guaranteed `startForeground()` on Service Creation**: Ensured `MediaPlaybackService.onCreate()` and `onStartCommand()` immediately call `startForeground()` within milliseconds of creation, completely eliminating Android's `ForegroundServiceDidNotStartInTimeException` crashes during video transitions.
- **Defensive Service Lifecycle Handling**: Wrapped `MediaPlaybackService.start()`, `MediaPlaybackService.stop()`, and `updateNotification()` in defensive try-catch handlers, preventing `ForegroundServiceStartNotAllowedException` and `IllegalStateException` during rapid video switching.
- **Bitmap Recycling Protection**: Added `!bitmap.isRecycled` guards and exception handling across `GeckoMediaSessionBridge.kt` and `MediaPlaybackManager.kt` before passing artwork bitmaps to `MediaMetadataCompat` and notification builders.

## 📱 Exhaustive Responsive UI/UX Architecture & Device Adaptation

### Adaptive Breakpoints & Layout Density Engine
- **`Responsive.kt` Foundation**: Introduced `rememberWindowSize()`, `AzokleBreakpoints`, and `Modifier.adaptiveContentWidth(maxWidth: Dp)` to adapt layouts automatically across phone, compact landscape (<520dp height), tablet/foldable (600–840dp), and desktop (>840dp).
- **Home & Discover Screens**:
  - Dynamically scale brand monogram size (`36.sp` on compact heights vs `54.sp` on standard/large displays) with adaptive vertical spacing.
  - Centered and constrained content width to `640.dp` on wide displays to prevent uncomfortable eye scanning.
- **Onboarding Carousel**:
  - Dynamically scales medallion size (`76.dp` vs `126.dp`) and typography for compact heights and landscape orientation.
- **Omnibar & Navigation Bar**:
  - Collapses secondary actions (Reader mode, settings) from top bar on compact screens (<360dp) so URL domain hierarchy remains legible and unfractured.
  - App bottom navigation bar is bounded to `500.dp` on tablets and protects against localized tab label squeezing on narrow devices.
- **Modal Bottom Sheets & Dialogs**:
  - Constrained all 10 modal bottom sheets (`SettingsSheet`, `ChooseLanguageSheet`, `ChooseSearchEngineSheet`, `BrowserMenuSheet`, `BrowserUrlEditSheet`, `LinkContextMenuSheet`, `PrivacyShieldSheet`, `SiteSettingsSheet`, `SiteSecurityCertificateSheet`, `SitePermissionPromptSheet`, `PwaInstallBottomSheet`) to a max-width of `560.dp` and centered them on tablets to avoid awkward horizontal stretching.
  - Dialogs (`InfoDialog`, `ProUpgradeDialog`) bound to `480.dp`.
- **Reader Mode & Touch Target Standardization**:
  - Bound article reading column to `700.dp` for optimal reading ergonomics.
  - Enforced minimum WCAG 2.2 AA compliant 44×44dp touch target bounding boxes across all icons, toggles, and action triggers.
